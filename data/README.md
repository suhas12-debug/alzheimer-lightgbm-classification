# Data Access Instructions

## ⚠️ Important Notice

The ADNI dataset is **not included** in this repository. ADNI data is governed by a Data Use Agreement and **cannot be shared publicly**.

---

## How to Get the Data

### Step 1 — Register for ADNI Access
1. Go to [https://adni.loni.usc.edu](https://adni.loni.usc.edu)
2. Click **"Apply for Data Access"**
3. Fill in your institution details and research purpose
4. Wait for approval (usually 1–3 business days)

### Step 2 — Download Required Files

Once approved, log in to the **LONI Image and Data Archive (IDA)** and download:

| File | Description | Location in IDA |
|------|-------------|-----------------|
| `ADNIMERGE.csv` | Main clinical + cognitive dataset | Study Data → Key ADNI tables → ADNIMERGE |
| `UCSFFSX7_*.csv` | FreeSurfer 7.x cross-sectional MRI volumes | Study Data → Imaging → FreeSurfer |

### Step 3 — Place Files

After downloading, place them as follows:

```
data/
├── raw/
│   ├── ADNIMERGE_<date>.csv
│   └── UCSFFSX7_<date>.csv
└── processed/
    └── ADNI_MRI_Cognitive_Merged.csv   ← generated by notebook 01
```

### Step 4 — Run Preprocessing

Open and run `notebooks/01_data_preprocessing.ipynb` to merge the two CSVs into the final dataset used for training.

## Features Used in This Study

### Cognitive Features (7)
| Feature | Description |
|---------|-------------|
| `AGE` | Patient age in years |
| `AGE_sq` | Age squared (derived) |
| `PTEDUCAT` | Years of education |
| `MMSE` | Mini-Mental State Examination score (0–30) |
| `ADAS13` | Alzheimer's Disease Assessment Scale-13 |
| `CDRSB` | Clinical Dementia Rating Sum of Boxes |
| `ADAS_gap` | MMSE − ADAS13 (derived cognitive gap) |

### MRI Features (3)
| Feature | Description |
|---------|-------------|
| `Hippocampus` | Hippocampal volume (mm³) from FreeSurfer |
| `Entorhinal` | Entorhinal cortex volume (mm³) from FreeSurfer |
| `H_E_ratio` | Hippocampus / Entorhinal ratio (derived) |
