# 🧠 Multimodal LightGBM Ensemble for Alzheimer's Disease Classification

> **Classifying Alzheimer's Disease (CN / MCI / AD) using Cognitive Scores and FreeSurfer MRI Biomarkers**
> 
> KLE Technological University, Hubballi, India

---

## 📌 Overview

This repository contains the full implementation of a multimodal machine learning framework for three-class Alzheimer's disease classification. Two separate LightGBM classifiers — one trained on cognitive features, one on structural MRI biomarkers — are combined through a weighted probability
