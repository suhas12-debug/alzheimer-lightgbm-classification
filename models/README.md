# Models

This folder contains trained LightGBM model artifacts.

| File | Description |
|------|-------------|
| `lgb_model_cog.joblib` | Trained cognitive LightGBM model |
| `lgb_model_mri.joblib` | Trained MRI LightGBM model |
| `scaler_cog.joblib` | StandardScaler for cognitive features |
| `scaler_mri.joblib` | StandardScaler for MRI features |
| `ensemble_params.joblib` | Ensemble weights and decision threshold |

> Models trained on ADNI public dataset.
> Not intended for clinical use.
